# Free public hosting options (checked 2026-09-17)

Scope: a small Python HTTP API (standard-library server or WSGI adapter), with a public URL and no assumed paid budget. “Free quota” means metered service that can bill or expire; “no-card” and “no-expiry” are separate properties. Provider policies can change, so re-check before launch.

## Recommendation

**Primary: PythonAnywhere Beginner**, if the app can be exposed as WSGI. It is the closest fit: a free Python web app at `<username>.pythonanywhere.com`, one worker, 512 MB private storage, and free SSL. It is not no-expiry: unused free web apps expire after one month, and outbound Internet is allow-listed. [Official plan comparison](https://www.pythonanywhere.com/pricing/); [free-account limits](https://helpdev.pythonanywhere.com/pages/FreeAccountsFeatures/); [expiry announcement](https://blog.pythonanywhere.com/221/).

**Fallback: Hugging Face Spaces Docker/ZeroGPU**, if the repository can be wrapped in a Docker Space and the account qualifies for the free personal ZeroGPU exception. Public Spaces have an `hf.space` URL and 50 GB non-persistent disk, but free compute sleeps after inactivity (currently about 48 hours); ordinary free Docker compute requires a paid plan. [Spaces overview](https://huggingface.co/docs/hub/spaces-overview); [sleep policy](https://huggingface.co/docs/hub/spaces-gpus#sleep-time).

## Bottom line

There is no credible option in this set that is simultaneously (1) no-card, (2) public, (3) full Python process/WSGI compatible, and (4) guaranteed never to expire or sleep. PythonAnywhere is the practical low-friction choice if monthly activity can prevent its one-month unused-app expiry. Hugging Face is the practical fallback for a public Dockerized demo, accepting sleep and non-persistent storage. Cloudflare Workers is a genuinely free public edge endpoint but requires adapting the API to its Python Worker model, so it is not a drop-in deployment of `http.server`/WSGI.
