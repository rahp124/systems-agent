One auditable investigation loop

The agent does not declare an incident type. It maintains uncertainty, values the evidence available next, and records how each observation changes the ranking.

  1. 01

    Hold competing explanations

    Begin with contamination, leak, and sensor-fault hypotheses rather than committing to the first plausible story.

  2. 02

    Value the next observation

    Estimate expected information gain for each available action, then divide by its relative cost.

  3. 03

    Update from returned evidence

    Apply the action likelihood to the current belief and preserve the evidence, score, and posterior for review.

  4. 04

    Repeat or stop

    Continue while evidence is useful and budget remains. The operator—not the agent—owns any operational response.

Decision rule next action = max expected information gainrelative cost Implemented in the live synthetic case above.
